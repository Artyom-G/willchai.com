# Projects host artwork

The active atlas is `public/assets/projects-v3/will-host.png`. Eighteen transparent 32 × 32 cells preserve the original Photography face, hair and palette. The exporter writes each frame individually, the atlas, and foot, hand and prop attachment coordinates. Display sizes are 192, 160 and 128 pixels.

The pose order is rest, wave, present, crouch, launch, air, land, point, blink, shift, look, reach, lift, hold, strain, place, turn and point_down. `scripts/build-projects-sprite.mjs` checks every pixel against the canonical palette and exports binary alpha. `src/data/projects-will-frames.json` supplies the shared controller with attachment coordinates. The displayed review atlas is in `artifacts/projects-review/native-host-atlas.png`.

The earlier study history follows for provenance.

Two studies used the built in image generation tool. The first changed the character’s identity. The second approached the visual style but returned RGB data with a painted background. Neither generated sheet is referenced by the page. The gestures informed the native pixel export. Future changes should preserve the native grid, alpha channel and canonical face.

The final study prompt was:

Use case: identity-preserve. Edit the supplied original pixel drawing into an animation atlas. The input is an integer enlargement of exact 32 × 32 pixel cells. Preserve its extremely simple block construction. The face has golden square glasses, peach skin, solid near black hair, a grey open jacket over a muted burgundy shirt, and near black straight trousers. Each eye is only one logical pixel. The head is about 8 logical pixels wide. The whole body is about 22 logical pixels high. Use exactly this character and its existing six flat colours. Keep head and torso pixels identical to the original clean standing frame. Change only the arms and legs to create eight host poses. Empty hands. Arrange a 4 column by 2 row atlas, every cell exactly 32 × 32 logical pixels with each logical pixel enlarged to an equal square block. Equal cells and consistent scale, ample transparent gutter inside cells. Reading order: relaxed standing, wave with raised forearm, open palm presenting to the right, crouch before jumping, takeoff with raised arms, airborne with bent knees, low landing, point toward upper right. Grounded feet end at logical row 28. Deliver an actual transparent PNG with zero alpha in all empty background pixels. The image contains only eight blocky figures. The background is completely empty and has a real alpha channel. Preserve six solid colours, hard edges, square blocks and identical original facial features. No painted checkerboard, no background colour, no shading, no anti aliasing, no dithering, no additional shades, no gradients, no fine detail, no camera, no strap, no suit or tie, no text, no lines between cells.
