# Project instructions

Use `WORKFLOW.md` to identify the active implementation surface and keep file
searches, status checks, staging, and builds path-scoped. Do not scan or rebuild
the legacy application, generated output, dependency tree, or original media
archive unless the user's request explicitly includes them.

Before changing the website's interface, identity, content structure, or copy,
read `DECISIONS.md`, `BRAND-GUIDELINES.md`, `DESIGN-SYSTEM.md`,
`CONTENT-GUIDE.md`, `system/README.md`, and `system/PATTERNS.md`. Use
`system/index.html` as the rendered visual reference and reuse values from
`system/tokens.css` rather than recreating brand constants inside individual
components.

Keep the system page and written sources synchronized whenever a durable design
or pattern decision changes. Preserve the two-family live-text system: Funnel
Sans for prose and interface roles, and Unbounded for selected display roles.
Plantagenet Cherokee belongs only to the outlined logo artwork and must not be
served as a font without an appropriate webfont licence.

Homepage project panels use a shared exterior size and authentic image-backed
art direction. Do not substitute solid section colours for media. The
Vermilion dashed outline is a selective signature and should not surround every
panel or control. Follow the canonical writing instruction in
`BRAND-GUIDELINES.md` for all AI-assisted copy.

Preserve the need for an authentic exception layer, but treat its visual
language as unresolved. New exceptions must be derived from personal or
project material rather than generic blobs, stickers, or pixel badges. Do not
normalize the holographic contact ticket into a generic button or spread its
foil treatment across unrelated components. Use the current compact W mark
from `system/assets/willchai-mark.avif`, keep all live text at
least 14px at default scale, and prefer 15px for recurring interface text.
